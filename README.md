# Digital Newsroom Editorial Workflow

A full-stack application that allows writers to create and submit articles, editors to review and approve them, and the newsroom to schedule and publish articles while maintaining a complete immutable history.

## Getting Started

1. Set up the backend:
   ```bash
   cd backend
   npm install
   npx prisma migrate dev
   npm run dev
   ```

2. Set up the frontend:
   ```bash
   cd frontend
   npm install
   npm run dev
   ```
